Buxus hedges

All Buxus is drip-watered at the roots from the back tap timer, including the hedge under the office window. The only bed not on it is left of the garage, where the hedge has box blight and is coming out.

Never spray Buxus leaves. Wet foliage spreads blight. Bag and bin the blighted hedge, clean tools afterwards, and don't replant Buxus in that spot.

Checking it's right

  • Tuna can test on the lawn: aim for about 10mm in the can per watering.
  • Finger test on beds: 5cm down should be moist a couple of hours after a run.
  • Lawn that doesn't spring back underfoot is thirsty.
  • Watch for Christchurch City Council watering restrictions in a dry summer.

Hunter X2

Use the dial for each section, then + − ◀ ▶ and PRG.

Date and time ▾
  1. Dial to DATE/TIME.
  2. Year flashes. + − to set, ▶ to move on.
  3. Repeat for month, day, then the time.
Start times ▾
  1. Dial to START TIMES.
  2. PRG until A shows. Set 5:00am.
  3. PRG to B. Set 5:00am.
  4. PRG to C. Press + − to 12:00AM, then − once more for OFF.
  5. Press ▶ to check start 2, 3 and 4 in each program. All should be OFF.
Run times ▾

Each zone has a run time in every program, so zones that don't belong need to be 0.

  1. Dial to RUN TIMES.
  2. PRG to A. ▶ through zones: 1 to 4 = 20 min, 5 to 8 = 0.
  3. PRG to B: 1 to 4 = 0, 5 to 7 = 15 min, 8 = 0.
  4. PRG to C: every zone 0.
Water days ▾
  1. Dial to WATER DAYS.
  2. PRG to A. + to water, − to skip: Mon, Wed, Fri on.
  3. PRG to B: Tue, Sat on.
Seasonal adjust and finish ▾
  1. Dial to SEASONAL ADJUST. Set the percentage for the month (see Schedule).
  2. Dial back to RUN and leave it there.
Rain delay: dial to OFF, wait for it to blink, set days with + or −, back to RUN. Run one zone: dial to MANUAL, ▶ to the zone, set minutes, back to RUN.

Holman CO1605 timers

T1 to T3 on the front manifold and T4 on the back tap. 9V battery, replace each spring.

Programming ▾
  1. MODE to TIME. Set the day and clock with + −, SET to move on.
  2. MODE to DURATION. Set minutes.
  3. MODE to DAYS. Turn on the days you want.
  4. MODE to STARTS. Set the start time.
  5. MODE back to the normal display.
ON runs it now. OFF stops it, handy after rain. Take timers inside over winter: frost cracks them.
Broken tap nut ▾

Holman sells the top connector separately as "Tap Timer Nut Spare Part, CO1600 Series" from their Australian online store. Bunnings doesn't stock it. Email support@holmanindustries.com.au to ask about shipping to NZ.

Holman WX1 Wi-Fi timers

Two from the old house, plus the Wi-Fi hub. They use the Holman Home app, not the Bluetooth app.

Setting up ▾
  1. Plug the hub into a power point inside, nearest the taps.
  2. Phone on TP-Link_IoT_F818 (the 2.4GHz IoT network).
  3. Holman Home app: +, Garden Watering, Wi-Fi Hub. Enter the IoT network password.
  4. Fresh AA batteries in each WX1. Tap the hub, Add/View Devices, follow the reset prompt.
  5. Name each timer and set the schedule under STARTS.
Timer won't pair? Remove the battery holder, wait 5 minutes, then hold the button while locking the holder back in.
